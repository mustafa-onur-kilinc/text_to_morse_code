# Text to Morse Code Converter

## What is Morse Code?

Morse code is a telecommunications method that encodes characters using signals with
two types of duration: dots (dits) and dashes (dahs).

Samuel Morse created the first Morse code system in 1837 and Alfred Vail expanded on it by adding letters and
special characters in 1840. Eight years later, Friedrich Gerke standardized dash length,
added umlaut vowels and CH in German and changed some of the encodings of characters.
His modified Morse code was used as a basis for International Morse code in 1865.

Originally developed for telegraphs, it was later used in radio communications,
aviation and helping people with disabilities to communicate [^1].

[^1]: https://en.wikipedia.org/wiki/Morse_code

## Characters and Their Morse Encodings

This code has Morse encodings of the Latin alphabet letters, numbers, punctuation
(both standard and non-standard) and non-Latin letters of "Ç", "Ö" and "Ü".

Turkish letters "Ğ", "İ" and "Ş" share the same Morse encoding with "G", "I" and "S" respectively.

For more information, you can check the 
[characters and prosigns table](https://en.wikipedia.org/wiki/Morse_code#Characters_and_prosigns) 
on Wikipedia's Morse code page.
